# Arcwell 2D Game
<i><b>This game is at the early development stage!</b></i>  

<b>Platform:</b> Windows 10/11  

<b>Controls</b>  
A - Move left;  
D - Move right;  
W/SPACE - Jump;  
E - Attack;  
T - Debug mode;  
ESC - Exit game.
