# Arcwell 2D Game
<i><b>This game is at the early development stage!</b></i>  

<b>Platforms:</b> Windows 10/11 x64, Linux 6.17+ x64, macOS 15+ x64 - <i>(not tested!)</i>  
<b>Requirements for compilation:</b> SDL2-2.0 for your platform

<b>Controls:</b> 

<i>[KEYBOARD]</i>  
A / Left - Move left;  
D / Right - Move right;  
K - Jump;  
L - Attack;  
SPACE - Pause/resume;  
F3 - Debug mode;  
ESC - Exit game.  

<i>[GAMEPAD (XBOX Version)]</i>  
D-Pad Left / LS - Move left;  
D-Pad Right / RS - Move right;  
A - Jump  
B - Attack  
Start - Pause/resume;  
Back - Exit game.
